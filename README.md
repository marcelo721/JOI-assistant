## 🧠 About

**JOI** is an intelligent voice assistant designed to provide a natural and interactive interface between the user and a physical embedded device.

This repository contains the **backend/server responsible for JOI's intelligence**, handling communication between the embedded device, artificial intelligence services and external APIs.

The backend acts as the central layer of the system:

```text
                 ┌──────────────────────┐
                 │       JOI Device     │
                 │   ESP32 + Microphone │
                 │   Display + Speaker  │
                 └──────────┬───────────┘
                            │
                           MQTT
                            │
                            ▼
                 ┌──────────────────────┐
                 │     JOI Backend      │
                 │      Java/Spring     │
                 └──────────┬───────────┘
                            │
             ┌──────────────┼──────────────┐
             │              │              │
             ▼              ▼              ▼
          ┌──────┐       ┌───────┐     ┌─────────┐
          │ Groq │       │ Azure │     │ Spotify │
          │  AI  │       │ TTS   │     │   API   │
          └──────┘       └───────┘     └─────────┘
```

The goal is to create a modular backend capable of processing voice interactions, understanding user commands, generating responses and controlling services through the JOI device.

## 📡 MQTT Communication

The JOI device communicates with the backend through **MQTT**.

The communication is divided into different topics according to the type of data being transmitted.

### Chat

```text
neva/+/chat/message
```

Messages sent by the device are received by the backend and processed by the AI pipeline.

### Text-to-Speech

Audio generated by the backend is streamed through MQTT.

```text
joi/{deviceId}/audio/tts/start
joi/{deviceId}/audio/tts/data
joi/{deviceId}/audio/tts/end
```

The audio is divided into chunks, allowing the device to start reproducing the response while the remaining audio is still being generated.

```text
Azure TTS
    │
    ▼
Audio Stream
    │
    ├── Chunk 1 ──┐
    ├── Chunk 2   │
    ├── Chunk 3   ├── MQTT ──► ESP32
    ├── Chunk 4   │
    └── Chunk N ──┘
```

This reduces the perceived latency between the user's request and JOI's response.

## 🤖 Artificial Intelligence

JOI uses **Groq** to process natural-language interactions.

The backend is responsible for:

1. Receiving the user's input.
2. Sending the request to the AI model.
3. Processing the generated response.
4. Determining whether the request is a normal conversation or an actionable command.
5. Forwarding the appropriate result to the device or an external service.

Example:

```text
"JOI, toque Blinding Lights"

        │
        ▼

     Groq AI

        │
        ▼

Intent: PLAY_MUSIC
Artist: The Weeknd
Song: Blinding Lights

        │
        ▼

Spotify Web API

        │
        ▼

Playback Command
```

## 🎵 Spotify Integration

JOI can communicate with the **Spotify Web API** to interact with the user's music library and playlists.

The backend handles the Spotify authentication flow using OAuth.

### Example

The user can say:

```text
"JOI, toque minha playlist favoritos"
```

The backend can:

```text
User command
     │
     ▼
   Groq
     │
     ▼
Extract intent
     │
     ▼
Search Spotify
     │
     ▼
Playlist ID
     │
     ▼
Spotify API
```

This allows natural language to be used instead of requiring the user to provide Spotify IDs manually.

## ⚙️ Configuration

Create an environment configuration containing the required credentials.

Example:

```env
# AI
GROQ_API_KEY=your_groq_api_key

# Azure Speech
AZURE_SPEECH_KEY=your_azure_speech_key
AZURE_SPEECH_REGION=your_azure_region

# Spotify
SPOTIFY_CLIENT_ID=your_spotify_client_id
SPOTIFY_CLIENT_SECRET=your_spotify_client_secret
SPOTIFY_REDIRECT_URI=http://127.0.0.1:8080/api/spotify/callback

# MQTT
MQTT_BROKER_URL=tcp://localhost:1883
MQTT_CLIENT_ID=joi-backend

# Database
DATABASE_URL=jdbc:postgresql://localhost:5432/joi
DATABASE_USERNAME=postgres
DATABASE_PASSWORD=your_password
```

> **Never commit API keys, passwords or OAuth credentials to the repository.**
